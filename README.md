# Zihinsel Mimari — Batuhan Personal Blog

**Zihinsel Mimari** is the public knowledge space of AlphaRayCorp, where physics, quantum mechanics, and system design meet. It is a professional technical blog and portfolio built to share research-driven insights, architectural thinking, and practical engineering perspectives.

## Tech Stack

- **Hugo (Go-based SSG):** Fast, reliable static site generation
- **Go:** Hugo runtime and tooling
- **LaTeX (KaTeX/MathJax):** Math rendering for equations
- **GitHub Actions:** CI/CD for automated builds and deployments

## Features

- Dark mode with user toggle
- Math rendering for scientific content
- SEO-optimized pages and metadata
- Automated deployment via GitHub Actions

## Run Locally

Make sure Hugo (extended) is installed.

```powershell
hugo server -D
```

Then open the local URL shown in the terminal (usually `http://localhost:1313`).
